# 予你花开 · 太阳雨中的日系花海与微缩渔港花墅 (Sunshower Japanese Flower-Sea & Harbor Diorama)

献给最爱的老婆 —— 一座零常驻 UI 干扰、支持第三视角自由拖拽旋转缩放与点击互动的 **Three.js 日系三渲二（Cel-Shaded）44m × 44m 花海、微缩海港与两室一厅童话花墅模型**。

## 场景特色

- **44m × 44m 超大幅正方形双剖面收藏级底座（`1,936 m²`）**
  - **码头与花崖岸壁剖面**：层层砌筑的湿润混凝土石块与花崖岩层剖面、深浅潮位线、3D 藤壶与牡蛎壳、随水摆动的海藻、系船环与锈蚀铁梯。
  - **23m × 23.5m 半透明海玻璃青水体剖面 + 海中樱花花礁**：透过青绿色水体截面直视水下斜坡碎石海床、沉底旧轮胎与锚链、童话珍珠贝、摇曳海草与 46 尾成群游动的彩色小鱼；外海伫立**海中樱花与绣球花礁小岛**（石灯笼、盛放樱树与绣球花丛），转角堆放消波块（テトラポッド）与翻涌白浪。
- **环抱港湾的日系海滨花海与樱花电车山坡（8,000+ GPU 随风摇曳 3D 花朵）**
  - **五大日系色带花田与飞舞花瓣**：粉蝶花天蓝、樱粉波斯菊、珊瑚玫瑰红、阳光油菜花金、玛格丽特白雏菊与薰衣草紫顺着起伏海岸草坡铺展，GPU 风浪着色器驱动花海层层起伏，空中飘落 320 片漫天樱瓣与花瓣。
  - **海岬铁艺花亭与双人花藤秋千**：花墅玫瑰拱门延伸出蜿蜒木栈道，通往西侧花海岬角上的纯白铁艺花亭与双人花艺秋千（点击可轻荡秋千并奏响花瓣竖琴琶音）。
  - **北侧樱花风车山坡与镰仓风复古海滨电车**：层叠花田山坡上矗立纯白旋转风车与盛放樱花林、红木拱桥山涧；山脚轨道上缓行着墨绿与奶油白配色的复古海滨单节电车（车厢内亮着暖灯，点击鸣响清脆叮当铃声），东侧绣球花海岬停靠着装满鲜花的薄荷绿复古单车。
- **L 形转角小渔港 + 三渲二色块化水面 + 太阳雨双彩虹**
  - 黄黑斜纹警示护轮坎、亲水石阶与低位登船平台、斜坡滑道（スロープ）与倒扣的小木舢板、内外双段防波堤与红白灯塔 / 薄荷绿航标灯。
  - 自定义 GLSL **色块化（Posterized）平涂倒影水面**：船身、救生圈、灯塔与海中樱花花礁倒影被切成边缘利落的青绿、深蓝、纯白、樱粉与珊瑚红碎块，伴随太阳雨丝、水滴涟漪、云隙暖金光柱与横跨海湾的淡彩双霓虹。
- **全通透室内与可掀顶「两室一厅」童话海景花墅**
  - **童话海景花墅（点击屋顶可平滑掀开）**：内含**一厅**（壁炉暖火、旋转黄铜留声机、双层草莓蛋糕圆桌、薄荷绿复古冰箱与铜锅厨房）、**主卧**（拼布双人床、百褶暖光台灯、复古衣柜与梳妆台）、**次卧**（40+ 藏书木书架、灯塔油画画架、木吉他与书桌火漆情书）。
  - **船只驾驶舱、渔协仓库与落地窗候船室**：透过玻璃窗可见船舵、雷达屏、鱼探仪、海图、保温壶、黄色雨衣与护身符；仓库内堆放鱼箱垛、冰柜、磅秤、挂墙雨靴、拍卖黑板与散落冰块；候船室内设木长椅、时刻表、老式收音机、热水壶、绿萝与微歪挂钟；台阶旁留着刚离开的两只银灰乐器硬箱与挂满雨珠的透明雨伞。
- **零常驻 UI + 3D 直接交互**
  - 左键/单指拖拽旋转、右键/双指平移、滚轮/双指缩放；点击**玫瑰信箱**或**书房火漆情书**即可展开专属信笺；点击屋顶、花海秋千凉亭、复古电车、白色风车、花篮单车、红白灯塔、泊位小船、乐器硬箱/雨伞与水下鱼群均可触发灵动反馈与海湾八音盒音效。
