# 梵高星月夜 · 繁花与满天星告白秘境

一片融合 **p5.js 梵高《星月夜》厚涂油画星空** 与 **Three.js 多品种 3D 繁花满天星草甸** 的浪漫交互秘境。

**在线访问： https://wide-sky-with-me.github.io/bloom-for-you/**

---

## 画面与创作工艺亮点

### 1. 上半境 · p5.js 梵高《星月夜》厚涂星空与圣雷米山柏（`site/vangogh-sky.js`）
- **分层抖动网格与多步弧形厚涂笔触（Tyler Hobbs 风格流场）**：基于分层网格铺设约 4,900 道二次贝塞尔厚涂油彩长笔触，依空间位置映射普鲁士蓝、群青、钴蓝、天青、象牙白与镉黄颜料，彻底告别随机碎屑短线。
- **天体切向偏转与有机同心星环（Petros Vrellis 流体涡旋灵感）**：流场笔触在靠近 11 颗主星与弦月时自动沿切向环绕偏转；每颗星辰由非对称多层厚涂短弧自然呼吸，右上角雕塑感镉黄弦月与星云辉映。
- **梵高火焰柏树与圣雷米远山（Saint-Rémy Horizon）**：左侧矗立 195 道 S 形上扬笔触绘就的梵高火焰柏树，远近双层靛蓝山脊以斜向油彩笔触过渡，与下半境 3D 草甸无痕相融。
- **油彩许愿流星与星云心形星座**：点击夜空或「召唤流星」划出金白厚涂拖尾流星；唤醒向日葵彩蛋或集齐全部心意后，漩涡星河上方浮现双色油彩笔触勾勒的**心形星座（Heart Constellation）**。

### 2. 下半境 · Three.js 六大立体繁花与油画夜色草甸（`site/flower-meadow.js`）
- **六种精细三维花朵与植物群落（零穿模空间排布 + 14,000 株迎风夜草）**：
  1. **蓝色无尽夏绣球（Hydrangea）**：22 丛自然分枝灌木 × 每丛 5 簇错落圆锥花球（共 7,200+ 朵四瓣蝶形小花）与锯齿阔叶环抱。
  2. **梵高星夜向日葵（Sunflower）**：34 朵高挑仰望月光的铬黄舌状花瓣向日葵，深褐螺旋花盘镶嵌金粉花药环与星状绿色花萼。
  3. **圣雷米紫蓝鸢尾（Royal Iris）**：58 株拱立内轮旗瓣 + 金须垂落外瓣鸢尾，基部簇生剑形叶片扇。
  4. **丝绒杯状庭园玫瑰（Velvet Rose）**：68 朵 28 片黄金角螺旋卷芯杯状玫瑰，深绯红、珊瑚粉与香槟金层层递进。
  5. **夜光百合杯郁金香（Moonlit Tulip）**：76 株修长微展六瓣郁金香，伴生抱茎披针叶随晚风轻摇。
  6. **满天星花云（Gypsophila）**：6,400 朵重瓣星光小花凝聚成 92 团蓬松星雾花簇与银河花带，穿插于大花与许愿瓶畔。
- **油画质感夜色着色器（Maxime Heckel 风格阶梯光影 + 次表面散射）**：月光主光采用 4 阶柔和色带与平滑漫反射混合，配合花瓣 UV 笔触微纹理、背光次表面透光（SSS）、深普鲁士绿夜草根部环境光遮蔽（AO）与单次 ACES 电影级色调映射。
- **指尖拨草与生物荧光波纹**：指针或手指掠过花丛时，花枝与 14,000 株草叶产生物理径向偏转，并扩散蓝金双色生物荧光脉冲波纹，220 只流萤在花叶间浮沉升空。

## 本地运行与测试

构建与测试仅需 Python 3.10+，Three.js `0.186.1` 与 p5.js `1.9.4` 均已锁版本自托管于 `site/vendor/`，运行时零外部 CDN 依赖：

```bash
python3 -m unittest discover -s tests -v
python3 build.py --output dist
python3 -m http.server 8000 --directory dist
```

浏览器访问 `http://localhost:8000` 即可体验。
