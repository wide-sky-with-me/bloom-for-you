# 梵高星月夜 · 童话花坡与提灯精灵秘境

一座融合 **p5.js 梵高《星月夜》厚涂油画星空**、**Three.js 高清叶脉拟真繁花**、**起伏草坡土坡与蜿蜒小路**、**自由漫游的提灯花帽小精灵** 以及 **13 处隐藏童话彩蛋** 的浪漫交互世界。

**在线访问： https://wide-sky-with-me.github.io/bloom-for-you/**

---

## 画面与创作工艺亮点

### 1. 上半境 · p5.js 梵高《星月夜》厚涂星空与圣雷米山柏（`site/vangogh-sky.js`）
- **分层抖动网格与多步弧形厚涂笔触**：铺设约 4,900 道二次贝塞尔厚涂油彩长笔触，依空间位置映射普鲁士蓝、群青、钴蓝、天青、象牙白与镉黄颜料。
- **天体切向偏转与有机同心星环**：流场笔触在靠近 11 颗主星与弦月时自动沿切向环绕偏转；左侧矗立梵高火焰柏树，远近双层靛蓝山脊与下半境童话山丘自然相接。
- **油彩许愿流星与星云心形星座**：点击夜空或「召唤流星」划出金白厚涂拖尾流星；唤醒山坡向日葵彩蛋或集齐心意后，漩涡星河上方浮现双色油彩勾勒的**心形星座（Heart Constellation）**。

### 2. 逼真植物花瓣纹理与三维花冠造型（`site/botanical-assets.js`）
- **512×512 程序化植物学纹理贴图 + Alpha 镂空边缘**：为每种花卉独立绘制放射叶脉、丝绒渐变、微缺刻波浪瓣缘与柔顺包裹光照（Wrap-Lambertian + 背光次表面透光 SSS + 丝绒边缘光泽），彻底告别纸片多边形感：
  1. **层叠庭园玫瑰（36 瓣五轮杯状玫瑰）**：内轮紧抱卷芯、外轮自然微翻，配丝绒放射叶脉贴图与茎生羽状绿叶。
  2. **蓝色无尽夏绣球（盘状四萼片团簇灌木）**：圆润微凹波浪萼片与中心小花蕊，16 丛饱满绣球灌木簇拥草坡与小屋花境。
  3. **梵高斐波那契向日葵（680 粒螺旋籽盘 + 40 枚脉纹舌状瓣）**：立体拱起黄金角螺旋花籽盘与金粉花药环，双圈修长脉纹花瓣仰望星月。
  4. **褶边有髯紫蓝鸢尾（Ruffled Bearded Iris）**：拱立内轮旗瓣 + 金白蜜导斑纹垂瓣与剑叶扇丛，盛放于右侧暖褐土坡与小水潭畔。
  5. **达尔文杯形郁金香（Darwin Goblet Tulip）**：圆润束腰六瓣酒杯花冠与粉金羽状脉纹。
  6. **满天星花云（Gypsophila）**：3,400 簇重瓣镂空星光小花沿蜿蜒小路两侧与花丛边缘铺成星雾花带。

### 3. 梦幻童话世界地形、小路与自由探索的提灯小精灵（`site/flower-meadow.js` & `site/fairytale-props.js`）
- **草原 · 土坡 · 蜿蜒小路 · 山丘小屋**：起伏青翠夜色草坡（18,000 株多色调柔风夜草）、陡坡自然显露的暖赭石土坡切面、铺有河卵石踏步的 S 形蜿蜒乡间土路，一路通往山丘顶上冒着星光烟圈的暖窗童话小屋。
- **自由探索的提灯花帽小精灵**：头戴倒扣风铃草花帽、扇动四片虹彩薄翼、手提金色星光小灯笼（实时动态暖光照亮脚下小路与身旁花瓣），既会在 11 处童话景点间自主漫步低语，也支持**点击草坡/小路任意位置唤她跑去探险**、**方向键 / WASD 操控漫步**以及一键切换 **「✧ 跟随精灵」第三人称漫游视角**。

### 4. 到处有彩蛋：5 封爱的告白信笺 + 8 处童话世界奇遇（共 13 处交互秘密）
- **5 封核心心意信笺**：草坡蓝色无尽夏、山坡向日葵与流萤、小路弯道丝绒玫瑰与星砂许愿瓶（完整珍藏致老婆情书）、右侧土坡紫蓝鸢尾与郁金香、星月夜漩涡许愿主星 + 终章盛典。
- **8 处童话秘境奇遇彩蛋**：山丘暖光童话小屋、土坡七彩唱歌蘑菇圈、岔路青鸟指路木牌、铁艺许愿风铃路灯、月光蒲公英绒球坡、星影睡莲露珠潭、苔藓树洞星光蜜罐、以及转身洒星尘的提灯花帽小精灵。

## 本地运行与测试

构建与测试仅需 Python 3.10+，Three.js `0.186.1` 与 p5.js `1.9.4` 均已锁版本自托管于 `site/vendor/`，运行时零外部 CDN 依赖：

```bash
python3 -m unittest discover -s tests -v
python3 build.py --output dist
python3 -m http.server 8000 --directory dist
```

浏览器访问 `http://localhost:8000` 即可体验。
