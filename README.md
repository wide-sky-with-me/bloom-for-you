# 予你花开 · 写实海景两室一厅花墅与漫山花海自由探索世界

献给最爱的老婆 —— 一座采用 **Three.js 物理写实渲染（PBR）** 构建的 **260m × 260m 海岸花海庄园、石砌游艇海港与 1:1 可自由步入探索的「两室一厅」海景花墅**。

## 场景与体验特色

- **1:1 真实建筑尺度 · 步入式「两室一厅」海景花墅（非掀顶玩具屋）**
  - **固定陶瓦坡屋顶与雪松横梁吊顶**：法式双开玻璃门与室内房门自然敞开，支持 `WASD` 键盘漫步或直接点击地板/门廊自由走入每一个房间，亦可随时切换高空全景俯瞰。
  - **阳光起居餐厅与开放式岛台厨房（一厅）**：人字拼橡木地板、石灰岩壁炉与跳动炉火、亚麻转角沙发、胡桃木六人餐桌与手雕多层玫瑰花瓶、卡拉卡塔大理石瀑布岛台与鼠尾草绿橱柜。
  - **海景主卧（一室）**：亚麻软包双人床、暖光百褶床头灯、整墙橡木衣柜、拱形铜镜梳妆台与面朝漫山薰衣草花海的落地窗纱帘。
  - **植物书房与次卧（二室）**：临窗卧榻、满墙精装藏书架、海岸油画画架、原声木吉他，以及阳光胡桃木书桌上封存专属信笺的**火漆情书**（点击即可展开阅读）。
- **植物学级写实花朵与多级分枝树木**
  - **黄金角螺旋 16 瓣立体玫瑰**：内层卷芯、中层杯状抱合、外层自然翻卷，搭配复叶锯齿玫瑰叶攀援于门廊花架、玫瑰拱门与信箱。
  - **4 类真实分枝树种（近百株）**：自然弯曲树干与法线贴图树皮，搭配高精度镂空叶脉与五瓣繁花枝丛，投射真实斑驳树影（海岸繁花樱杏、白桦与橡树、地中海橄榄树、意大利海岸丝柏）。
  - **数万株随风起伏的写实草甸与立体野花海**：45,000+ 渐变草叶与 24,000+ 立体波斯菊、普罗旺斯薰衣草花穗、玛格丽特白雏菊、粉蝶花及百余丛多层绣球花。
- **260m × 260m 辽阔海岸半岛与物理海洋天空**
  - 瑞利/米氏大气散射天空、阳光积云、远山海湾地平线，以及具备菲涅尔反射、水深比尔-朗伯青蓝吸收与岸边碎浪泡沫的写实海面。
  - 花岗岩海港码头、游艇与单桅帆船、防波堤石砌灯塔、海岬白石铁艺秋千花亭、山涧雪松木拱桥与山顶石砌风车全部连通可自由探索。
