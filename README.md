# 梵高星月夜 · 童话花坡与提灯精灵秘境

一座融合 **p5.js 梵高《星月夜》厚涂油画星空**、**Three.js 高清叶脉拟真繁花**、**起伏草坡土坡与蜿蜒小路**、**自由漫游的提灯花帽小精灵** 以及 **13 处隐藏童话彩蛋** 的浪漫交互世界。

**在线访问： https://wide-sky-with-me.github.io/bloom-for-you/**

---

## 画面与创作工艺亮点

### 1. 上半境 · p5.js 梵高《星月夜》厚涂星空与圣雷米山柏（`site/vangogh-sky.js`）
- **分层抖动网格与多步弧形厚涂笔触**：铺设约 4,900 道二次贝塞尔厚涂油彩长笔触，依空间位置映射普鲁士蓝、群青、钴蓝、天青、象牙白与镉黄颜料。
- **天体切向偏转与有机同心星环**：流场笔触在靠近 11 颗主星与弦月时自动沿切向环绕偏转；左侧矗立梵高火焰柏树，远近双层靛蓝山脊与下半境童话山丘自然相接。
- **油彩许愿流星与星云心形星座**：点击夜空或「召唤流星」划出金白厚涂拖尾流星；唤醒山坡向日葵彩蛋或集齐心意后，漩涡星河上方浮现双色油彩勾勒的**心形星座（Heart Constellation）**。

### 2. 逼真植物花瓣纹理与三维花冠造型（`site/botanical-assets.js`）
- **512×512 程序化植物学纹理贴图 + Alpha 镂空边缘**：为每种花卉独立绘制放射叶脉、丝绒渐变、微缺刻波浪瓣缘与柔顺包裹光照（Wrap-Lambertian + 背光次表面透光 SSS + 丝绒边缘光泽），彻底告别纸片多边形感：
  1. **层叠庭园玫瑰（36 瓣五轮杯状玫瑰）**：内轮紧抱卷芯、外轮自然微翻，配丝绒放射叶脉贴图与茎生羽状绿叶。
  2. **蓝色无尽夏绣球（盘状四萼片团簇灌木）**：圆润微凹波浪萼片与中心小花蕊，16 丛饱满绣球灌木簇拥草坡与小屋花境。
  3. **梵高斐波那契向日葵（680 粒螺旋籽盘 + 40 枚脉纹舌状瓣）**：立体拱起黄金角螺旋花籽盘与金粉花药环，双圈修长脉纹花瓣仰望星月。
  4. **褶边有髯紫蓝鸢尾（Ruffled Bearded Iris）**：拱立内轮旗瓣 + 金白蜜导斑纹垂瓣与剑叶扇丛，盛放于右侧暖褐土坡与小水潭畔。
  5. **达尔文杯形郁金香（Darwin Goblet Tulip）**：圆润束腰六瓣酒杯花冠与粉金羽状脉纹。
  6. **满天星花云（Gypsophila）**：3,400 簇重瓣镂空星光小花沿蜿蜒小路两侧与花丛边缘铺成星雾花带。

### 3. Blender 4.0 精致细分建模（`.glb` PBR 资产）与自由探索的提灯小精灵（`tools/generate_blender_models.py`、`site/fairytale-props.js` & `site/flower-meadow.js`）
- **5 组自托管 Blender 4.0 Catmull-Clark 细分雕刻 `.glb` 模型资产（`site/assets/models/`）**：
  - `fairy_sprite.glb`：盲盒手办级关节分体小精灵（暖瓷脸颊、清漆高光蓝宝石眼眸与星芒追光点、10 缕渐层金发、波浪翻边风铃草花帽与星铃、八瓣渐变花裙、卷尖精灵短靴、藤蔓牧羊杖与六角黄铜星灯）。
  - `storybook_cottage.glb`：吉卜力绘本风山丘小屋（约 148 片独立倒角石板瓦片层叠屋顶、半木构橡木梁柱、拱形木门、玫瑰花箱与苔藓鹅卵石台阶）。
  - `mushroom_cluster.glb`：4 种弯曲球茎菌柄、蕾丝菌环裙、24 片放射立体菌褶与凸起立体波点的荧光毒蝇伞，组成会随音乐弹跳的七彩蘑菇圈。
  - `fairytale_landmarks.glb`：停驻胖青鸟的榫卯木路牌、卷草铁艺许愿风铃路灯、盘根古树洞星光蜜罐、水晶星砂许愿瓶、**跨路攀援蔷薇星灯花拱门（`RoseArchProp`）**、**全三维斐波那契冠毛蒲公英绒球簇与降落伞瘦果种子（`DandelionClusterProp` & `DandelionSeedMesh`）**、**苔石睡莲露珠潭与戴皇冠小青蛙王子（`DewPondProp` & `FrogPrinceNode`）**，以及圆润河卵石踏步网格（`CobbleStoneMesh`）。
  - `botanical_blooms.glb`：40 瓣高心螺旋大卫奥斯汀玫瑰 + **五裂反卷玫瑰花萼果托（`RoseCalyx`）**、**38 瓣双圈纵沟波浪向日葵舌状花 + 总苞片花托（`SunflowerRays` & `SunflowerCalyx`）**、达尔文酒杯郁金香、带花柱冠的褶边有髯鸢尾、饱满无尽夏四萼绣球（含中心珍珠小花蕾），以及 **3,400 簇立体双层杯状满天星小花云（`GypsophilaCluster`）**。
- **草原 · 土坡 · 蜿蜒小路 · 星夜 PMREM 环境反射**：起伏青翠夜色草坡（18,000 株多色调柔风夜草）、陡坡自然显露的暖赭石土坡切面、铺有河卵石踏步的 S 形蜿蜒乡间土路，配合程序化星夜 `PMREMGenerator` 环境光与提灯/路灯/小屋实时暖色点光源（`THREE.PointLight`）。
- **自由探索的提灯花帽小精灵**：既会在 11 处童话景点间自主漫步低语，也支持**点击草坡/小路任意位置唤她跑去探险**、**方向键 / WASD 操控漫步**以及一键切换 **「✧ 跟随精灵」第三人称漫游视角**。

### 4. Scroll-World 一镜到底滚动飞越引擎（`site/scroll-world-engine.js`）
- **借鉴 `oso95/scroll-world` 的无缝分段飞越架构**：将 7 章浪漫叙事（序章星夜入口 → 无尽夏与睡莲露珠潭 → 高心玫瑰与水晶星砂瓶 → 紫蓝鸢尾与唱歌蘑菇圈 → 攀援蔷薇花拱门与向日葵 → 穿过花门抵达山丘暖光小屋 → 梵高星河终章）与 6 段二阶贝塞尔航线衔接弧编织为 13 段连续时间轴（`SEGMENTS`），各接缝位置零跳变（`seam delta = 0.000m`），支持正反向丝滑滚动拖动（`rAF` 平滑插值）。
- **`lingerEase` 章节微距驻留与双端原生构图**：采用单调三次驻留曲线在每章文案峰值处自动放缓镜头，桌面端自动将三维主体置于右中黄金视觉区（避开左侧毛玻璃叙事卡），移动端竖屏（`≤ 860px`）采用原生 `9:16` 机位将主体置于上半屏（避开底部安全区卡片）并屏蔽地址栏伸缩引起的滚动跳动。
- **双模式自由切换**：默认进入 **「📜 漫游飞越」**（含顶部流光进度条、右侧 7 节点航线导览轨 `sw-route` 与章节互动按钮），亦可一键切回 **「✧ 自由探索」** 或 **「跟随精灵」** 360° 自由漫游。

## 本地运行与测试

构建与测试仅需 Python 3.10+，Three.js `0.186.1` 与 p5.js `1.9.4` 均已锁版本自托管于 `site/vendor/`，运行时零外部 CDN 依赖：

```bash
python3 -m unittest discover -s tests -v
python3 build.py --output dist
python3 -m http.server 8000 --directory dist
```

浏览器访问 `http://localhost:8000` 即可体验。
