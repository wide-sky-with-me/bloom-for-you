# 予你花开 · 太阳雨中的童话星语花湾 (Sunshower Fairytale Harbor Diorama)

献给最爱的老婆 —— 一座零 UI 干扰、支持第三视角自由拖拽旋转缩放与点击互动的 **Three.js 三渲二（Cel-Shaded）微缩海港与两室一厅童话小屋模型**。

## 场景特色

- **正方形双剖面收藏级底座（`24m × 24m`）**
  - **码头岸壁剖面**：层层砌筑的湿润混凝土石块、深浅潮位线、3D 藤壶与牡蛎壳、随水摆动的海藻、系船环与锈蚀铁梯。
  - **半透明海玻璃青水体剖面**：透过青绿色水体截面直视水下斜坡碎石海床、沉底旧轮胎与锚链、童话珍珠贝、摇曳海草与成群游动的小鱼，转角堆放消波块（テトラポッド）与翻涌白浪。
- **L 形转角小渔港 + 三渲二色块化水面**
  - 黄黑斜纹警示护轮坎、亲水石阶与低位登船平台、斜坡滑道（スロープ）与倒扣的小木舢板、短防波堤与红白相间灯塔、远山绿树与瓦顶童话民家。
  - 自定义 GLSL **色块化（Posterized）平涂倒影水面**：船身、救生圈与灯塔倒影被切成边缘利落的青绿、深蓝、纯白与珊瑚红碎块，随波变形、碎裂、重组，点缀暖金粼光。
- **全通透室内与可掀顶「两室一厅」童话海景花墅**
  - **童话海景花墅（点击屋顶可平滑掀开）**：内含**一厅**（壁炉暖火、旋转黄铜留声机、双层草莓蛋糕圆桌、薄荷绿复古冰箱与铜锅厨房）、**主卧**（拼布双人床、百褶暖光台灯、复古衣柜与梳妆台）、**次卧**（40+ 藏书木书架、灯塔油画画架、木吉他与书桌火漆情书）。
  - **船只驾驶舱内景**：透过玻璃窗可见船舵、微光雷达屏与鱼探仪、海图与潮汐表、保温壶与搪瓷杯、挂钩黄色雨衣、窗边护身符与照片。
  - **渔协仓库与落地窗候船室**：半拉起卷帘门与高窗光柱下的鱼箱垛、冰柜、磅秤、挂墙雨靴、拍卖黑板与散落冰块；候船室落地窗内的木长椅、时刻表、老式收音机、热水壶、绿萝与微歪挂钟。
  - **刚离开的温柔痕迹**：台阶旁并排的两只银灰乐器硬箱与挂满雨珠的透明雨伞。
- **零常驻 UI + 3D 直接交互**
  - 左键/单指拖拽旋转、右键/双指平移、滚轮/双指缩放；点击屋顶、玫瑰信箱/火漆情书、红白灯塔、泊位小船、乐器硬箱/透明雨伞、自动贩卖机与水下鱼群均可触发互动与八音盒/海港音效。
