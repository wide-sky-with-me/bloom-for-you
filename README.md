# 梵高星月夜 · 繁花与满天星告白秘境

一片融合 **p5.js 梵高《星月夜》厚涂油画星空** 与 **Three.js 多品种 3D 繁花满天星草甸** 的浪漫交互秘境。

**在线访问： https://wide-sky-with-me.github.io/bloom-for-you/**

---

## 画面与交互亮点

### 1. 上半境 · p5.js 梵高《星月夜》与满天星河（`site/vangogh-sky.js`）
- **厚涂旋转星云流场（Impasto Curl Flow Field）**：离线底图铺设 3,400+ 道普鲁士蓝、钴蓝、群青与松石绿油彩笔触，实时叠加 850 道沿双涡旋流场流动的发光笔触。
- **同心虚线星环与金色弦月**：11 颗主星与右上角金色新月均由多层旋转油彩断续光环包裹，数千颗细碎「满天星」星尘在夜空中呼吸闪烁。
- **油彩许愿流星与心形星群**：点击夜空或「召唤流星」即可划出金白厚涂拖尾流星；唤醒向日葵彩蛋或集齐全部心意后，夜空浮现金色油彩勾勒的**心形星座（Heart Constellation）**。

### 2. 下半境 · Three.js 六大立体繁花与满天星草甸（`site/flower-meadow.js`）
- **六种精细三维花朵造型（Instanced Parametric Geometry）**：
  1. **蓝色无尽夏绣球（Hydrangea）**：冰川蓝、矢车菊蓝、紫罗兰与初遇幻彩粉多球簇生，四瓣十字蝶形小花带金色花蕊。
  2. **梵高星夜向日葵（Sunflower）**：双层错落亮金舌状花瓣围绕斐波那契螺旋暖褐花盘，高挑仰望星空。
  3. **梵高紫蓝鸢尾花（Royal Iris）**：三片直立内轮旗瓣 + 三片垂落带金黄花须的外轮垂瓣。
  4. **丝绒庭园玫瑰（Velvet Rose）**：24 片黄金角螺旋包裹的内卷杯状花瓣，胭脂红、香槟粉与珊瑚柔粉交织。
  5. **夜光郁金香（Moonlit Tulip）**：6 片优雅杯状抱合花瓣，随晚风轻柔摇曳。
  6. **满天星花云（Gypsophila）**：成千上万朵星光白与冰蓝五瓣小花如银河雾气般穿插在所有大花之间。
- **指尖拨草与生物荧光脉冲波纹**：指针或手指掠过花丛时，花枝产生物理径向偏转，并向四周扩散蓝金色生物荧光能量波纹，百余只双色流萤在花叶间穿梭浮沉。

### 3. 花丛与星河里的「5 大爱的告白彩蛋 + 终章盛典」（`site/assets/confessions.json` & `site/gift.json`）
1. **彩蛋 I · 发光无尽夏与满天星**：《初遇 · 星河落进花丛》
2. **彩蛋 II · 梵高向日葵与流萤心群**：《奔赴 · 仰望同一片星月夜》（点亮夜空心形星群）
3. **彩蛋 III · 丝绒玫瑰与星砂许愿瓶**：《珍藏 · 玫瑰花荫下的时光信笺》
4. **彩蛋 IV · 梵高鸢尾与并蒂郁金香**：《相守 · 鸢尾的骑士与郁金香的晚安》
5. **彩蛋 V · 梵高星月夜涡旋与许愿流星**：《永恒 · 漩涡星河里的千万次许愿》
- **终章盛典**：寻获全部 5 处心意（或点击手账中的终章按钮）后，触发油彩流星雨、心形星座常亮与全场繁花荧光波纹，同时右上角「爱的信笺」完整保留致老婆的专属情书（`site/gift.json`）。

## 本地运行与测试

构建与测试仅需 Python 3.10+，Three.js `0.186.1` 与 p5.js `1.9.4` 均已锁版本自托管于 `site/vendor/`，运行时零外部 CDN 依赖：

```bash
python3 -m unittest discover -s tests -v
python3 build.py --output dist
python3 -m http.server 8000 --directory dist
```

浏览器访问 `http://localhost:8000` 即可体验。
